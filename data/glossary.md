# GitHub 中文化 · 术语表与翻译规范

## 铁律

1. **只翻译 GitHub 界面自身的固定文案**。用户名、仓库名、组织名、项目名、代码、URL、邮箱、版本号、品牌名一律丢弃（不要翻译，也不要保留进词典）。
2. **宁缺毋滥**：不确定是否为固定 UI 文案的条目，直接丢弃，不要猜测。
3. **简体中文**；按钮/菜单用简短动词（尽量 ≤6 字）；说明性长句可完整翻译。
4. 保留原文的省略号（…）、问号、冒号、括号等标点结构；中文标点用全角。
5. 术语必须按下表统一，不得自创译法；同一英文在不同页面保持同一译法。
6. 输出 JSON：`{"英文原文": "中文译文"}`，UTF-8，无注释、无尾逗号；键必须与输入文本逐字一致（不要改大小写、不要改省略号样式）。
